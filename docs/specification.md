# 車中泊スポットブログ Specification

## Product Summary

車中泊で旅行したスポットと、訪問時に感じたことを紹介する旅ブログ。

主導線は「地図 → 都道府県 → 市区町村 → スポット記事」。

初期版では地図・地域導線・記事閲覧に集中し、名称検索・ジャンル検索は後続対応にする。

## Audience

主な読者は、車中泊旅行の候補地を探している個人旅行者。

読者が知りたいことは以下。

- 実際に泊まりやすい場所か
- どの地域にあるスポットか
- 訪問時にどのような印象だったか
- 地図からどのように探せるか

## Content Model

スポット記事は以下の情報を持つ。

- 名称
- 都道府県
- 市区町村
- ジャンル
- 本文
- 訪問日

記事URLのslugはmicroCMSのコンテンツIDを使い、地域slugと座標はデプロイ時に自動生成する。編集者はこれらを入力しない。

道路状況、設備、周囲の様子などの訪問メモは専用フィールドを設けず、本文に記述する。

## Location Policy

所在地を一般公開して差し支えない施設だけを記事として公開する。都道府県ページのピンは地域内のおおよその位置を把握する案内として扱う。

## Pages

### Top

- 都道府県を選べる白い日本地図
- 都道府県導線
- 最新記事

### Prefecture Page

- 都道府県内の市区町村一覧
- スポット一覧
- 都道府県の白地図と公開可能な記事スポットのピン

### Municipality Page

- 市区町村内のスポット一覧
- 市区町村内の公開可能な記事スポットを示す都道府県地図

### Spot Article

- 旅行記本文
- スポット基本情報
- 訪問日

## Map Interaction

- 全国地図の表示要素は日本地図だけとし、都道府県内へ固定ラベルや説明文を置かない。
- 都道府県をhoverまたはfocusすると都道府県名をツールチップで表示し、選択すると都道府県ページへ移動する。
- 都道府県地図の表示要素は境界と記事スポットのピンを基本とし、固定ラベルや説明文を置かない。
- 公開可能なピンは表示時に上から順次落下する。OSで動きを減らす設定が有効な場合はアニメーションしない。
- ピンをhoverまたはfocusするとスポット名と記事リンクを表示する。タッチ操作でも同じ情報へ到達できるようにする。
- 座標検索に失敗した記事はピンを表示せず、スポット一覧から記事へ移動できるようにする。
