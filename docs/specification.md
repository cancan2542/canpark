# 車中泊ハザード検証ブログ Specification

## Product Summary

車中泊で旅行したスポットを紹介しながら、ハザードマップ上の危険度と現地で見た実感を併記する旅ブログ。

主導線は「地図 → 都道府県 → 市区町村 → スポット記事」。

初期版では地図・地域導線・記事閲覧に集中し、名称検索・ジャンル検索は後続対応にする。

## Audience

主な読者は、車中泊旅行の候補地を探している個人旅行者。

読者が知りたいことは以下。

- 実際に泊まりやすい場所か
- ハザードマップ上でどのような危険があるか
- 地図だけでは分からない現地の不安要素があるか
- 災害時に避難や移動がしやすそうか

## Content Model

スポット記事は以下の情報を持つ。

- 名称
- slug
- 都道府県
- 市区町村
- ジャンル
- 本文
- 写真
- 訪問日
- 公開日
- 更新日
- 座標
- 位置公開レベル
- 公式サイト/施設リンク
- ハザード確認日
- ハザード確認元URL
- 自治体ハザードマップURL
- 公式確認メモ
- 洪水・土砂災害・津波・高潮の危険度
- 現地Tips

現地Tipsには以下を記述する。

- 面している道の広さ
- 体感的な標高、周辺より低い/高い印象
- 集落や人家の近さ
- 逃げ道の分かりやすさ
- 夜間の安心感
- 通信状況
- トイレや水場などの利用感
- 悪天候時に避けたい理由

## Hazard Rating

初期版で扱う公式ハザード項目は以下。

- 洪水
- 土砂災害
- 津波
- 高潮

各項目は危険度として表示する。

- `1`: 低リスク
- `2`: やや低リスク
- `3`: 注意
- `4`: 高リスク
- `5`: 非常に高リスク
- `未確認`
- `該当なし`

総合スコアは出さない。

危険度は安全保証ではなく、確認時点の公式ハザード情報をもとにした個人の整理として扱う。

## Location Policy

道の駅、RVパーク、公式に車中泊が許可・想定されている施設は正確な座標を表示する。

非公式または迷惑化しやすい場所は、市区町村または周辺エリアまでにぼかす。

位置公開レベルは記事ごとに設定する。

- `exact`: 正確な座標を公開
- `approximate`: 周辺エリアのみ公開
- `municipality`: 市区町村単位のみ公開
